# Ejercicio Packet Tracer

Red con 3 routers (Oeste, Centro, Sur) enlazados por seriales, RIP v2 y rutas estáticas, 3 switches, 3 PCs y 3 servidores (HTTP, DNS, FTP).

- `ejercicio_PT-9.0.1.pkt`: archivo original, para Packet Tracer 9.0.1.
- `ejercicio_PT-8.2.2.pkt`: reconstrucción para Packet Tracer 8.2.2 (la 8.2 no abre archivos de la 9.x). Los servicios de los servidores no se copiaron, solo sus IPs.
